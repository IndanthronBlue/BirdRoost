# 功能清单

这里是羽栖桌面端的完整功能清单。README 只保留最常用的路径；需要逐项核对时看这一页。

## 整理与识别

- **图形界面**：基于 PySide6，跟随系统浅色／深色外观并支持运行时切换，API Key 使用掩码输入；可选保存到 macOS 钥匙串，默认不写入配置文件。
- **额度查询**：手动查询并显示懂鸟图像识别的已用量、总额度和剩余量。
- **识别范围**：支持鸟类、哺乳类、两栖类、爬行类，以及可搜索的国家／地区选项。
- **多目标识别**：按 API 返回的检测框分别处理；同一张照片的不同鸟种分别归档，同一鸟种出现在多个检测框中仍只归档一次。
- **逐目标人工复核**：低置信度或候选接近时，在原图上高亮当前检测框并显示候选及置信度。“稍后处理”只推迟当前目标，不影响其他目标继续复核和归档；原图同时复制一份到 `待复核/`，同图多个推迟目标不重复复制。
- **待复核框标注**：有检测框的推迟目标会在 `待复核/` 再生成一张带橙色框和目标编号的副本；API 未返回检测框时只复制原图。
- **同群同样处理**：复核弹窗可勾选“后面同样”，把当前鸟种一次套用到本图后续未确认目标；每个目标仍单独记录，同种只复制一次。
- **人工鸟名归档**：候选都不正确时可直接输入鸟种中文名归档；同图相同鸟名只复制一次，不同鸟名分别归档。
- **断点续跑**：在源目录维护 `birdclass_records.csv`，跳过已完成图片，恢复待复核目标或识别后尚未完成复制的任务，不重复上传。
- **大图自动处理**：超过 2 MB 或边长超过 8192 像素的图片，使用临时压缩副本上传；识别后清理临时文件，归档仍使用原图。
- **可配置等待**：结果查询默认总等待 60 秒，可在 1～600 秒之间调整。
- **元数据写入**：原图写入全部已确认鸟种，复制件写入所属鸟种，便于后续搜索。
- **规范命名**：复制件按观测地点、观测时间、鸟种和递增编号命名。
- **额度保护**：可用额度不足时停止提交新图片；已识别或待复核任务仍可继续处理。
- **额度复查**：批次结束后重新查询实际额度并更新显示；复查失败只记录警告，不推翻已完成结果。
- **启动预检**：开始前检查源目录可读、目标目录可写，避免处理到一半才发现路径问题。
- **安全退出**：运行中关闭窗口时提示“停止并退出/取消关闭”；停止会等待当前图片处理完成。
- **错误落盘**：复制、配置和网络错误写入 `failed`，保留识别/归档快照，下次优先续拷而不是重复上传。
- **统一配置**：顶部“配置…”集中管理懂鸟 API Key 和 COS 桶/地域/Endpoint/用户前缀/Secret，Secret 可选存 macOS 钥匙串。
- **从云端同步（pull）**：本地干净时 fast-forward，增量下载缺失原图，应用远端 tombstone；本地有未推送修改时拒绝覆盖。
- **tombstone 清理**：扫描超过保留期且不再被 manifest 引用的云端对象，预览确认后删除。
- **冲突快照**：覆盖前保存远端 manifest 到 `.birdroost/cloud_conflicts/`，冲突窗口展示本地/云端差异。
- **云端索引优化**：上传前一次 `list_objects` 建立云端对象索引，减少逐对象 HEAD。
- **定时清理**：可选每 7 天自动清理过期 tombstone 对象。
- **云端冲突处理**：revision 冲突时停止上传，可确认后强制用本地 manifest 覆盖云端。
- **云端自动同步**：纠错、删除、修改观测信息后，2.5 秒防抖自动更新云端 manifest（仅 manifest，不重复上传原图）。
- **云端恢复**：新电脑可从 COS 下载 manifest 和全部原图，校验 SHA-256 后重建本地 `.birdroost`。
- **云备份（M1）**：生成 SHA-256 去重清单和缩略图，并可通过界面把原图/缩略图上到腾讯云 COS；支持用户前缀、可选 Endpoint、连接测试和可选的 COS 配置记忆（Secret 存 macOS 钥匙串）。
- **归档浏览**：按界门纲目科属种虚拟分类树浏览分类后目录，支持搜索、缩略图和动态更新；新物种归档后无需重启查看器；同一时间只保留一个浏览窗口，已打开时按钮置灰。
- **SQLite 索引**：`.birdroost/index.sqlite` 缓存图片、group、批次和观测地，可删除重建；分类树按增量方式更新，不因新增一张图整树重建。
- **观测地筛选**：可按观测地过滤，并支持按文件名、观测时间、修改时间、物种名排序。
- **批次问题清单**：批次页可查看失败和待复核 group 的状态、源文件、观测地、错误说明和副本路径。
- **观测信息**：批量分类时选择国家（可输入联想）、中国时的省份、自由填写地点和月份；查看页双击观测地/时间即可修改单张照片所属 group 的信息。
- **地点筛选**：观测地是“国家抽屉”，默认只展开国家，进入国家后再选地区/地点；中国走三级，国外走国家/地点；筛选后左侧分类树只保留当前观测地有照片的物种分支。
- **人工复核入口**：待复核/失败图片可直接人工填写鸟名（支持中文/拼音首字母联想），或标记为无鸟、非鸟动物（点击后直接移动，随后在“非鸟动物”节点内设置备注名）、风景、已分类、稍后处理；待复核页面的“已分类”按钮位于目标列表下方；同图全部目标确认后自动移除待复核副本；人工归档按目标逐个处理：只归档当前选中目标，其他待复核目标保留；若该物种已有副本则复用、不重复复制；所有目标完成后才移出待复核；操作后停留在待复核视图并选中下一张。

- **删除照片**：当前归档副本可二次确认后移到 `已删除/`，不直接永久删除。
- **结果确认**：批次结果页提供“确认结果并关闭”按钮，确认后直接关闭本次结果窗口。
- **全屏/比较**：查看页或双击缩略图进入 Lightbox，可用“显示检测框”或 B 键切换框；可 Ctrl/Cmd 选中两张图片，或先点“比较”固定第一张、跨物种再选第二张，左右并排、各自独立缩放和拖动。
- **快捷浏览**：图片网格支持方向键切换当前图片；摘要显示总图片数和已归档鸟种数。
- **自定义检索别名**：可在详情页为 IOC 物种添加自己的中文别名，别名只参与搜索/联想，不改变 IOC 正式名。
- **可调详情布局**：右侧图片区和下方详情区之间可上下拖动，图片可放大、详情可滚动。
- **中文分类树**：分类树可在中文、中英、拉丁三种显示间切换，默认中文；左侧树、中间缩略图、右侧图片三栏可拖动调整宽度。
- **快速搜索**：支持中文、英文、拉丁名、路径、拼音全拼和拼音首字母；输入时自动联想，回车选中第一个结果或图片；搜索时自动跨当前分类树分支全局查找。
- **快速打开**：归档窗口先显示“正在读取归档…”提示，缩略图按可见区域异步加载，不再因一次性解码全部图片而卡住。
- **批次结果页**：每批结束默认自动打开，只显示本批结果和汇总；可在设置中关闭自动打开。
- **检测框显示**：归档时把检测框写入输出目录的 `.birdroost` 库；查看页默认隐藏，可切换显示，批次页默认显示。
- **缩放与剪贴板**：查看页和人工复核弹窗支持缩放/拖动；查看页可复制干净图或带框图到剪贴板。
- **归档纠错**：查看页可按副本修改分类，批次页可按目标修改；支持中文别名和自定义人工鸟名，整份副本直接移动，不额外复制到 `已纠正/`，不改源图、不改 CSV。
- **旧数据补框**：可从旧的 `birdclass_records.csv` 导入批次和检测框数据，不需要源图；旧版遗留的 `已纠正/` 副本可在查看页清理。
- **分类学树**：内置 IOC World Bird List v15.2 中文/英文/拉丁名快照，覆盖中国与西古北界物种，并支持异体中文名。
